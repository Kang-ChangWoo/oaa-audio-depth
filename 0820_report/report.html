0. 과제와 용어 — 이것만 알면 아래를 다 읽을 수 있음

과제: 로봇 리그가 "삑" 소리(처프)를 내고, 몸에 달린 마이크 2~8개로 58ms 동안 메아리를 녹음한다. 이 녹음만으로 360° 깊이 지도(각 방향의 벽까지 거리, 0~10m)를 예측한다. 소리는 1m를 갔다 오는 데 약 5.8ms 걸리므로 녹음의 시간축이 곧 거리축이다: 3m 벽의 첫 메아리는 17ms쯤, 8m 벽은 47ms쯤에 도착한다. 녹음 뒷부분에는 "먼 벽의 첫 메아리"와 "가까운 벽들 사이를 여러 번 튕긴 메아리"가 겹쳐 있다.

기준 모델(OAA-CNN): 논문의 모델. 마이크별 스펙트로그램을 작은 CNN(15.4M 파라미터)으로 인코딩하고, 마이크의 위치·방향 정보를 쓰는 기하 attention으로 합쳐 깊이 지도를 만든다. 이 캠페인은 이 CNN 인코더 하나만 사전학습된 오디오 파운데이션 모델(AFM, ViT-B/16 86M)로 바꾸고 나머지는 전부 그대로 둔다 — 그래야 성능 차이가 인코더 하나로 귀속된다.

r2 / fb / r6 / r8
마이크(관측) 2 / 4 / 6 / 8개 구성. 많을수록 정보가 많아 문제가 쉬워진다.
MAE
예측 깊이와 정답의 평균 오차(미터). 낮을수록 좋다. near/mid/far = 정답이 3m 미만 / 3–6m / 6m 초과인 픽셀만 따로 계산한 오차.
val / test
val = 학습 중 모델 선택용 검증 점수, test = 최종 평가. 이 캠페인에서 val 순위와 test 순위가 자주 뒤집혀서(박빙일 때 절반), 모든 결론은 test 기준이다.
시드(seed)
같은 설정을 난수만 바꿔 다시 학습한 것. 점수가 ±0.005~0.012 흔들리므로, 격차가 0.01 이하인 비교는 시드 2~3개 평균으로 판정했다.
LLRD
Layer-wise LR Decay. 사전학습 모델을 미세조정할 때 아래층(범용 특징)은 거의 안 건드리고(학습률 2e-6) 위층만 크게(5e-5) 조정하는 방법. 층마다 0.75배씩 줄인다.
vdrop
학습 중 마이크 몇 개의 입력을 무작위로 0으로 만드는 정규화(mic drop).
사전학습 목적함수
AFM이 AudioSet(유튜브 소리 200만 개)에서 "무엇을 맞히도록" 훈련됐는가. 5개 백본은 아키텍처·데이터가 같고 이것만 다르다 — EAT=가려진 부분의 특징 맞히기(masked), SSLAM=여러 소리를 섞어 놓고 각각을 복원하기(mixture), AudioMosaic=변형해도 같은 소리임을 알기(contrastive), BAT=분류에 안 중요한 부분을 게이트로 끄기(gated), M2D-CLAP=텍스트 의미와 정렬(CLAP).
결론 세 줄
① AFM 인코더는 평가된 대부분의 설정에서 CNN과 동등하거나 그 이상이며, 개선이 가장 뚜렷한 곳은 관측이 적거나(2·4ch) 데이터가 어려운(MP3D) 조건이다. 판정 규칙: 시드 분산(±0.005~0.012)을 고려해 평균 격차 0.01 미만은 동률(tie)로 처리한다. 이 기준으로 확정 승 5칸·동률 1칸·CNN 승 1칸·학습 중 2칸(MP3D 6/8ch sslam은 표에서 eat 기준).
② 사전학습 방식(formulation)과 전이 성능 사이에 강한 경향이 있다: far 오차 순위가 mixture < masked < CLAP < contrastive < gated. 단, 공개 모델들은 loss 외에 마스킹·증강 등 세부 레시피도 다르므로 "결정한다"가 아니라 "강하게 시사한다"가 정확하고, 인과 확정에는 EAT→(+mixture 목적함수만 추가) 통제 사전학습이 필요하다(§5).
③ 분석 실험이 직접 보여주는 것: CNN은 초기 구간 정보에 훨씬 민감하고(온셋 삭제 시 sslam의 1.5~2.4배 하락), SSLAM의 추가 정확도는 늦은 잔향 구간에 강하게 의존하며(꼬리 삭제 시 우위 소멸), 그 활용은 정밀한 시간 배열에는 둔감하다(섞기 무해). 이를 잇는 해석 — "CNN=도착시각·진폭 앵커, SSLAM=분산 잔향 정보" — 은 데이터와 잘 맞는 가설이며, 남은 인과 간극은 §3의 대조 실험으로 닫는 중이다.

3. 메커니즘: SSLAM은 정말 잔향을 읽어서 이기는가? — 분석 실험 6종

학습 없이, 이미 학습된 모델들에게 조작한 test 입력을 주고 성적 하락(Δ)을 쟀다. 조작은 파형 단계에서 시간 구간을 지우거나 섞는 방식이다. 이 데이터의 파형은 렌더링된 임펄스 응답이라, "직접음"(스피커→귀로 바로 오는 소리, 방 정보 없음)이 항상 49번째 샘플에 있는 폭 1.5ms짜리 스파이크임을 먼저 확인했다 — 그래서 시간 기준으로 깨끗하게 잘라낼 수 있다.

실험 A. 직접음 삭제(earlyzero) — CNN이 무엇에 의존하는지

무엇을: 녹음 맨 앞(직접음 포함 왕복 1m 구간)을 0으로. 방 정보는 거의 안 지워진다(1m 이내 벽만 영향). 결과: CNN Δ+0.71, eat +0.46, sslam +0.29 — CNN이 2.4배 붕괴. 데이터가 직접 말하는 것: CNN이 초기 음향 정보에 훨씬 민감하다. 가설(분리 필요): 지워진 것에는 직접음 앵커·초기 도착시각·초기 에너지·국소 스펙트럼이 함께 들어 있어, "도착시각인가 진폭 기준인가"는 이 실험만으로 구분되지 않는다 — §3의 추가 실험 G(직접음의 위치만 이동 vs 크기만 변경)가 이를 분리한다.

실험 B. 삭제 + 볼륨 복원(renorm) — "큰 신호가 빠져 통계가 뒤틀린 탓" 가설 검증

무엇을: A처럼 지운 뒤 파형 전체 에너지를 원래대로 되돌림. 만약 A의 하락이 볼륨 통계 때문이면 회복돼야 한다. 결과: 세 모델 모두 오히려 더 나빠짐(CNN +0.71→+0.81). 데이터가 직접 말하는 것: "전체 에너지(RMS)가 작아져서"라는 단순 설명은 기각된다. 범위 한정: 전체 에너지만 복원했을 뿐 국소 시간 포락선·스펙트럼 분포·국소 SNR은 복원되지 않았으므로, 이 실험이 모든 통계적 설명을 배제하는 것은 아니다. (AFM은 내부 per-sample 정규화가 있어 전역 스케일 충격은 원래 자동 보정된다.)

실험 C. 꼬리 삭제 위치 스윕(latecut 3~9m) — sslam 우위의 "주소"

데이터가 직접 말하는 것: (1) sslam의 추가적인 mid 정확도(CNN 대비 우위분)는 해당 벽들의 1차 도착 창 바깥, 즉 늦은 잔향 관측에 강하게 의존한다 — 1차 메아리를 안 쓴다는 뜻이 아니라, 1차에 더해 꼬리를 활용하며 우위분이 꼬리에서 나온다는 뜻이다. (2) 절벽이 없다 = 그 의존이 한 시점이 아니라 꼬리 전체에 얇게 분산되어 있다. CNN처럼 한 곳(온셋)에 몰려 있으면 실험 A처럼 한 방에 무너진다.

실험 D. 구간별 구멍(notch) — 어느 시간대가 어느 거리를 책임지나

범위 한정: far 슬롯 없이 far를 맞힌 것이 "남은 음향 증거로부터의 재구성"인지 "이런 근거리 구조의 방이면 먼 벽은 대개 이 정도"라는 학습 데이터의 방 모양 prior인지는 이 실험으로 구분되지 않는다. 구분하려면 근·중거리는 같고 먼 벽만 다른 반사실(counterfactual) 샘플 쌍에서 예측이 실제 먼 벽을 따라가는지 봐야 한다(§5 미래 방향).

실험 E. 꼬리 순서 섞기(shuffle) — 구조를 읽나, 통계를 읽나

무엇을: 6m 이후를 지우는 대신 0.2m 블록 단위로 순서만 무작위로 섞음(에너지는 그대로). 결과: 세 모델 모두 거의 무해(Δ+0.003~0.008; 지우면 +0.09~0.15). 데이터가 직접 말하는 것: 0.2m 블록 단위의 전역 배열은 중요하지 않다. 아직 열려 있는 것: 블록 내부(0.2m 이하)의 국소 무늬는 보존됐으므로, "전역 에너지 통계만 읽는다"와 "국소 무늬 조각들을 순서 무관하게 모아 쓴다(bag-of-patches)"는 아직 구분되지 않는다 — 블록 크기를 0.02~1m으로 바꿔가며 어느 해상도부터 무너지는지 보는 스윕(실험 H)이 이를 판정한다. 현재 안전한 표현: "sslam은 꼬리의 미세한 전역 배열에 상대적으로 둔감하며, 분산된 잔향 특성을 활용하는 것으로 보인다".

실험 F. 시드 재현 — 위 결과가 우연인가

무엇을: 독립적으로 다시 학습한 모델들(CNN 재학습판, sslam 시드1, sslam LLRD판)로 A·C를 반복. 결과: 방향 전부 재현(온셋 삭제 시 CNN이 1.55배 붕괴, 꼬리 의존은 AFM이 CNN의 4~7배). 단 크기는 시드마다 출렁임(예: 8-10m 의존도 0.195→0.040) — 독립 학습 간 같은 정성적 비대칭이 재현되나, 개별 교란 효과의 크기는 상당히 변동한다 — 메커니즘 그래프는 단일 시드 수치가 아니라 시드 평균±표준편차로 읽어야 하며(보강 실험 진행 중), 특정 숫자를 메커니즘의 고정 특성으로 인용해서는 안 된다.

메커니즘 서사(현 증거가 가장 자연스럽게 지지하는 그림) — CNN과 SSLAM 모두 초기 메아리를 사용한다. 다만 CNN의 표현은 초기·국소 단서에 크게 집중되어 있어 그 단서가 교란되면 급락하고, SSLAM은 같은 정보에 더해 늦은 잔향 필드에 분산된 증거까지 활용할 수 있어 어떤 단서가 사라져도 하락이 완만하다. "SSLAM이 늦은 도착의 정확한 시각을 읽는다"가 아니라 "잔향 필드의 분산 정보를 활용한다"로 두면 셔플 결과와도 모순이 없다. 상대 하락률(ΔMAE/기준 MAE)로 봐도 결론은 유지된다: earlyzero에서 CNN 272% vs sslam 115%.

남은 인과 간극과 닫는 실험(진행 중): G. 직접음의 시각만 이동 vs 크기만 변경 — CNN의 의존이 타이밍 앵커인지 진폭 보정인지 분리 · H. 셔플 블록 크기 스윕(0.02~1m) — 통계 vs 국소 무늬 판정 · I. 1차 창 × 꼬리 2×2 제거 — 두 성분의 독립 기여 분해 · F+. 시드 3개 평균±표준편차로 메커니즘 수치 보강. 추가 한계: 하드 제로 마스킹은 학습 분포 밖(OOD) 입력을 만들므로, 모든 Δ에는 "단서 상실"과 "낯선 입력" 효과가 섞여 있다 — 모델 간 차이는 유효하지만 절대 크기는 보수적으로 읽어야 한다.

4. 그 외 확정된 실무 법칙 (전부 test·다시드 근거)

  • LLRD는 유일한 "공짜 점심": EAT/SSLAM 계열(post-norm 구조)은 균일한 학습률로 미세조정하면 학습 중반에 val이 튀며 사전학습이 파괴된다. LLRD가 이를 고치면 전 대역이 같이 좋아진다 — 유일하게 부작용 없는 개입.
  • vdrop(마이크 드롭)은 조건부: 지울 여유(중복)가 있는 8ch + 깨끗한 Replica에서만 이득(+6.5%). 4/6ch에선 각 3시드로 해로움 확인, MP3D는 전 채널 해로움 — AFM의 잔향-통합 입력을 지우는 셈이라서.
  • 근거리 보완 시도는 Replica에선 제로섬: conv 패치 stem, AbsRel 로스(λ 0.2/0.05) 모두 near를 고치는 만큼 mid/far를 망침. 단 같은 convstem이 거친 MP3D에선 순이득(4ch 신기록 0.7617) — 개입의 가치는 데이터셋의 병목(정밀도 vs 강건성)에 달렸다.
  • EchoDiffusion이 8ch에서 오히려 나빠지는 이유: 채널을 위치 정보 없이 평균/스택으로만 합치는 구조(pose-blind)라 6ch에서 포화 — 같은 mic-drop도 OAA엔 이득, eco엔 손해였던 대비가 그 증거.
